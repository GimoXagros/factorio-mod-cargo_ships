# Cargo Ships

## Source version and installation

This checkout contains `cargo-ships` version `0.0.25`. [info.json](info.json) declares Factorio `0.16`; this does not establish compatibility with newer Factorio versions.

Select a package for your installed game version on the [Mod Portal downloads page](https://mods.factorio.com/mod/cargo-ships/downloads). Portal packages may differ from this source checkout. Put the downloaded ZIP in your Factorio user data `mods` directory and install the dependencies listed in its manifest (`?` marks optional dependencies).

This fork has no GitHub Releases.

Original attribution is recorded in [info.json](info.json).
